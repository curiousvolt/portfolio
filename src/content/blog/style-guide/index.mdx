## 1. Clean Rounded Callouts (No Boring Left Line)

Callouts now feature **smooth rounded corners (`rounded-2xl`)**, subtle elevated card backgrounds, and category-specific icons. The old left border line has been replaced with modern, balanced all-around card styling.

<Callout type="note" title="Information Note">
Use this for contextual explanations, background details, or architectural notes that support the main text without interrupting the reading flow.
</Callout>

<Callout type="tip" title="Pro Tip / Best Practice">
Performance optimizations and tactical advice look best in tip callouts. For example: leverage client-side PDF rendering to reduce server compute by 90%.
</Callout>

<Callout type="decision" title="Product Decision">
When writing product case studies, use the decision callout to highlight key strategic trade-offs, scope decisions, and core product bets.
</Callout>

<Callout type="warning" title="Warning / Edge Case">
Alert readers to potential pitfalls, breaking API changes, or critical security requirements.
</Callout>

<Callout type="important" title="Important Requirement">
Use for essential prerequisites, non-negotiable compliance rules, or key metrics milestones.
</Callout>

### How to use Callout in your MDX:

```mdx
import Callout from '@/components/Callout.astro'

<Callout type="tip" title="Pro Tip">
  Your custom advice or explanation goes here.
</Callout>
```

## 4. Code Blocks & Syntax Highlighting

Powered by **Expressive Code**, code blocks feature line numbers, copy buttons, file titles, and dark/light adaptive syntax highlighting:

```typescript title="src/lib/metrics.ts" {4,9-11}
export interface FunnelMetric {
  step: string;
  conversionRate: number;
  dropoffPercentage: number;
}

export function computeFunnelHealth(events: number[]): FunnelMetric[] {
  // Highlighted lines emphasize critical algorithms
  return events.map((count, idx) => ({
    step: `Phase ${idx + 1}`,
    conversionRate: (count / (events[0] || 1)) * 100,
    dropoffPercentage: 100 - (count / (events[0] || 1)) * 100,
  }));
}
```

## Summary Checklist for MDX Authors

- **Callouts**: Use `<Callout type="tip | note | decision | warning | important">` instead of boring lines.
- **Presentations**: Use `<GoogleSlides src="..." title="..." />` for 16:9 interactive slides.
- **PDFs**: Use `<DocumentEmbed src="..." title="..." />` for whitepapers and documentation.
- **Code**: Use standard triple backticks with language and optional `title="..."`.
- **Tables**: Use standard markdown pipe tables; they are automatically styled and responsive.
